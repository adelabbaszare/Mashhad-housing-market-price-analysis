## 📌 معرفی پروژه

این پروژه یک **تحلیل اکتشافی جامع داده‌ها (EDA)** را بر روی آگهی‌های فروش آپارتمان در **مشهد، ایران** انجام می‌دهد. هدف اصلی، شناسایی عوامل مؤثر بر قیمت مسکن و نمایش روندهای مرتبط با موقعیت مکانی، امکانات و ویژگی‌های ملک است.

این تحلیل می‌تواند برای خریداران، فروشندگان و تحلیلگران بازار املاک که به دنبال شناخت بهتر پویایی بازار مسکن مشهد هستند، اطلاعات ارزشمندی فراهم کند.

## 📂 دیتاست

این تحلیل بر اساس دیتاست **Mashhad Apartment Sales Data** منتشرشده در Kaggle انجام شده است:

**دیتاست:** [Mashhad Apartment Sales Data](https://www.kaggle.com/datasets/adelzare/mashhad-apartment-sales-data/data)

فایل اصلی داده‌ها با نام `mashhad_apartment_sales_2025.csv` شامل **22,403** رکورد آگهی فروش آپارتمان و ویژگی‌های زیر است:

| ویژگی | توضیحات |
| :--- | :--- |
| **neighborhood** | منطقه یا محله ملک در شهر مشهد. |
| **area** | مساحت آپارتمان بر حسب مترمربع. |
| **construction_year** | سال ساخت ساختمان بر اساس تقویم شمسی. |
| **rooms_count** | تعداد اتاق خواب. |
| **floor** | شماره طبقه واحد. |
| **total_floors_count** | تعداد کل طبقات ساختمان. |
| **unit_per_floor** | تعداد واحدهای موجود در هر طبقه. |
| **has_elevator** | مشخص می‌کند ساختمان آسانسور دارد یا خیر. |
| **has_parking** | مشخص می‌کند واحد دارای پارکینگ است یا خیر. |
| **has_warehouse** | مشخص می‌کند واحد دارای انباری است یا خیر. |
| **Price(Toman)** | قیمت آگهی به تومان. |
| **Price(USD)** | قیمت آگهی تبدیل‌شده به دلار آمریکا. |
| **created_at_date** | تاریخ ایجاد آگهی بر اساس تقویم میلادی. |
| **created_at_shamsi** | تاریخ ایجاد آگهی بر اساس تقویم شمسی. |

## 📊 یافته‌ها و تحلیل‌های اصلی

نوت‌بوک پروژه تحلیل‌های زیر را پوشش می‌دهد:

### 1. توزیع قیمت
- **مشاهده:** توزیع قیمت‌ها دارای چولگی به راست است. بخش عمده آپارتمان‌ها در محدوده **۱ تا ۴ میلیارد تومان** قرار دارند و آپارتمان‌های بسیار گران‌قیمت به‌عنوان نقاط پرت ظاهر می‌شوند.

### 2. قیمت در برابر مساحت
- **همبستگی:** بین مساحت (مترمربع) و قیمت رابطه خطی مثبت و قابل‌توجهی مشاهده می‌شود. همان‌طور که انتظار می‌رود، آپارتمان‌های بزرگ‌تر معمولاً قیمت بالاتری دارند.

### 3. ارزش‌گذاری محله‌ها
- **مناطق مورد بررسی:** تحلیل برای محله‌هایی با تعداد آگهی قابل‌توجه (بیش از ۵۰ مورد) انجام شده است.
- **بالاترین میانگین قیمت:** محله‌هایی مانند **سجاد، هاشمیه و کوه‌سنگی** در میان مناطق با میانگین قیمت بالاتر قرار گرفته‌اند.

### 4. تأثیر تعداد اتاق‌ها
- **روند:** میانه قیمت با افزایش تعداد اتاق‌ها به‌طور محسوسی افزایش می‌یابد. آپارتمان‌های دو و سه‌خوابه نسبت به واحدهای یک‌خوابه افزایش قیمت مشخصی نشان می‌دهند.

### 5. سن ساختمان
- **تراکم:** بیشترین حجم معاملات مربوط به ساختمان‌های **۰ تا ۱۰ ساله** است.
- **ارزش:** املاک جدیدتر معمولاً ارزش بالاتری دارند و با افزایش سن ساختمان، قیمت‌ها به‌تدریج کاهش می‌یابند.

### 6. تأثیر امکانات
- **آسانسور:** آپارتمان‌های دارای آسانسور به‌طور میانگین تقریباً **دو برابر** آپارتمان‌های بدون آسانسور قیمت دارند.
- **پارکینگ و انباری:** وجود هر دو ویژگی، ارزش قابل‌توجهی به قیمت ملک اضافه می‌کند.

## 🛠️ فناوری‌های استفاده‌شده

- **Python 3.x**
- **Pandas و NumPy:** برای پردازش، پاک‌سازی و مدیریت داده‌ها.
- **Matplotlib و Seaborn:** برای مصورسازی و تحلیل آماری داده‌ها.

## 📈 مصورسازی‌ها

*توجه: این ریپازیتوری شامل کدهای لازم برای تولید نمودارهای زیر است:*

1. **توزیع قیمت:** هیستوگرام توزیع قیمت آپارتمان‌ها.
2. **قیمت در برابر مساحت:** نمودار رگرسیون برای نمایش رابطه بین مساحت و قیمت.
3. **محله‌های برتر:** نمودار میله‌ای ۲۰ محله با بالاترین قیمت، با فیلتر حداقل ۵۰ آگهی.

6. **تأثیر امکانات:** نمودارهای میله‌ای مقایسه‌ای برای نمایش تأثیر آسانسور، پارکینگ و انباری بر قیمت.
